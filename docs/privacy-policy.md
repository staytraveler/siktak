# 개인정보 보관·삭제 정책 (PRD 16장)

> 작성: 2026-10-21 · 우연한 식탁 · 앱의 "내 프로필 → 개인정보 보관·삭제" 화면과 같은 내용

## 수집·이용
- 신청·매칭·안내에 꼭 필요한 정보만 받는다: 이름, 연락처, 출생연도, 성별, 직업(선택), MBTI·관심사·성향, 식사 조건(가격대·못 먹는 음식·알레르기).
- 다른 참가자에게는 매칭 전에 아무 정보도 보이지 않고, 확정 후에도 이름 첫 글자 수준의 제한된 소개만 보인다. 사람별 선호·차단·신고 내용은 상대에게 절대 공개하지 않는다.

## 보관 기간
| 정보 | 보관 |
|---|---|
| 프로필·연락처 | 회원으로 있는 동안. 탈퇴 즉시 삭제 |
| 신청·결제·환불·참석 기록 | 결제·환불 분쟁 대응과 운영 통계를 위해 탈퇴 후에도 **식별 정보 없이** 보관 |
| 피드백·사람별 선호 | 다음 매칭 품질을 위해 식별 정보 없이 보관 |
| 신고·차단·이용 제한 기록 | 안전 목적으로 탈퇴 후에도 보관 (재가입한 사람을 가려내기 위함) |
| 단체방 메시지 | 같은 테이블 참가자의 안전을 위해 운영 기간 동안 보관 |

## 삭제 요청과 탈퇴
1. 참가자는 앱의 **내 프로필 → 탈퇴·개인정보 삭제**에서 직접 요청한다.
2. 진행 중인 신청(결제 대기·매칭 대기·확정·대체 일정 선택 대기·환불 처리 중)이 있으면 먼저 취소하거나 끝나야 한다.
3. 탈퇴하면 이름·연락처·비밀번호·프로필이 즉시 삭제되고 로그인이 막힌다. 표시 이름은 "탈퇴한 회원"이 된다.
4. 위 표의 기록은 식별 정보 없이 남는다.

## 이 MVP에서의 범위
- 시연용 고정 계정(demo01·user01 등)은 심사 흐름이 깨지지 않도록 탈퇴할 수 없다. 로그인 화면의 "새 참가자로 시작하기"로 만든 계정은 실제 탈퇴가 동작한다.
- 보관 기간 만료 후 자동 파기와 개인정보 열람 요청은 실서비스 전환 때 정한다.
