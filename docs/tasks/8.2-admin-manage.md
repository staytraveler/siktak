## 작업
1. **회차 관리 `/admin/slots`** (2.3 것 확장): 생성·수정(날짜·시간·지역·정원·신청 마감·매칭 실행 시각), 상태 표시. 매칭 시각 수정 시 작업 실행기 재등록.
2. **식당 재고 `/admin/venues`**: 식당 CRUD(지역·주소·지도 링크·가격대·큐레이션 문구), 회차별 수용 테이블 수 편집. V2 영역(`venue`)이지만 **API·화면 추가는 허용**, 배정 로직(`VenueAssignmentService`)은 건드리지 마.
3. **매칭 설정 `/admin/settings`** (MAT-15): 가중치 S1~S6(합 100 검증), 최소 점수. `settings` 테이블 저장, 다음 실행부터 적용(실행 시 params 스냅샷은 이미 됨).
4. **신청자 목록 `/admin/applicants`**: 회차 필터, 4개 상태 컬럼, 프로필 요약, 이전 참석·신고 이력 → **CSV 내보내기**(신청자 목록 + 테이블 결과 2종, PRD 16장). UTF-8 BOM(엑셀 한글 깨짐 방지).
5. **피드백·안전 `/admin/feedback`**: 회차·테이블별 만족도 평균, 재참여·추천 의향, 코멘트 목록, 신고 목록(7.2 API) + 조치 버튼. **사람별 선호(AVOID/WANT_AGAIN)는 집계 숫자만**, 누가 누구를 골랐는지는 표시하지 않는다(PRD 16장).
6. **다음 일정 추천 알림 연결**: 피드백 제출 시 `NEXT_SLOT_RECOMMEND` 알림(V2 템플릿, 7.2 추천 결과 3개) — 이벤트 발행 한 줄로.
