## B. 로그인·권한 (40분)
- `POST /api/v1/auth/login` (loginId, password) → JWT(Access 토큰, 만료 24시간이면 충분, Refresh 없음). `GET /api/v1/auth/me`.
- `X-User-Id` 임시 인증 제거 → `Authorization: Bearer`. 운영자 API(`/api/v1/admin/**`)는 `OPERATOR`만, 참가자 API는 `PARTICIPANT`·`OPERATOR`.
- 데모 도구 API도 운영자만.
- 프론트: `/login` 화면(아이디·비밀번호) + **"테스트 계정으로 로그인" 버튼 목록**(admin, demo01, user01, user14, user23 — 심사위원이 한 번에 들어가도록). 토큰은 localStorage, axios 인터셉터로 헤더 부착, 401이면 `/login`.
- 기존 사용자 선택 드롭다운 제거.
- 디자인은 하지 않는다 (UI 톤앤매너는 사용자 컨펌 후 9.x).
- 카카오 로그인은 하지 않는다 (P1).
