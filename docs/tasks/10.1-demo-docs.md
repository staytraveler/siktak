## 2. README.md (저장소 루트) 갱신 — 심사위원이 읽는 문서
1. 한 줄 소개 + 핵심 원칙 "정상 흐름은 자동, 운영자는 예외만"
2. 링크: 참가자 앱 `https://siktak-rho.vercel.app`, 운영자 `/admin`, API Swagger `https://siktak.onrender.com/swagger-ui.html`(실제 경로 확인)
3. 테스트 계정 표: 운영자 `admin` / `siktak-admin!`, 시연 참가자 `demo01`, 일반 참가자 비밀번호 `siktak1234` (실제 시드와 대조해서 틀리면 시드 기준으로 고치고 완료 보고에 적기)
4. **첫 접속 안내**: Render Free라 첫 요청이 최대 1분 걸릴 수 있음
5. 자동화 흐름 다이어그램(텍스트/mermaid): 신청→결제→매칭→재배치→식당 배정→확정·단체방→리마인드→체크인→피드백→다음 추천
6. 기술 스택·아키텍처 요약(포트/어댑터: PaymentGateway·NotificationSender·ContentGenerator, Mock 전환 설정값)
7. 로컬 실행 방법(.env.example 기준, 시크릿 값은 절대 쓰지 않기)
8. 문서 지도: `docs/prd-analysis.md`, `docs/domain/*`, `docs/erd.md`, `docs/decisions.md`, `docs/demo-scenario.md`
