## 1. 데모 시계
- `DemoClock extends Clock`: 실제 시각 + offset. offset은 **메모리에 보관**하고 변경 시에만 `settings.demo.clock-offset`에 저장, 기동 시 1회 로드 (매 `now()`마다 DB 조회 금지).
- `demo.enabled`(환경변수 `SIKTAK_DEMO_ENABLED`, 기본 true) false면 offset 0 고정, 데모 API 404.

## 2. 시간 기반 작업 실행기
- `ScheduledJobRegistry`(메모리): `(jobType, targetId, dueAt)` 목록. 1분 `@Scheduled` 틱은 **메모리만** 보고, `dueAt <= clock.now()`인 것만 실행.
- 작업 등록원: 앱 기동 시 1회 DB에서 적재 + 회차 생성·수정 시 갱신. 이번에 붙일 작업은 **`MATCH_RUN`(회차의 `match_run_at`)** 하나. 실행은 현재 `TableMatcher`(가짜 순차 매칭) 경로를 그대로 쓴다. (V2 엔진 연결은 4.4)
- **기동 시 catch-up**: 이미 지났는데 실행 안 된 작업은 즉시 실행 (decisions.md). 멱등이라 중복 실행 안전.
- 시계를 앞당기면 즉시 틱을 한 번 돌려 도래한 작업을 실행.
- ShedLock은 작업이 실제로 실행될 때만.
- 이후 작업 타입(`REMINDER_D1`, `CONTENT_POST`, `EVENT_END`, `RESOLUTION_TIMEOUT` 등)을 쉽게 추가할 수 있게 인터페이스로.

  - **식당(venues)·대화 콘텐츠·알림 템플릿은 해당 테이블이 생기는 5.x에서** 시드에 추가한다. 지금 테이블 없음.
