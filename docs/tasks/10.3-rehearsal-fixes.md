## 작업
1. **재배정 후 장소 안내**: 식당 예외 → 수용량 늘려 재배정되면 해당 테이블 구성원에게 "장소가 정해졌어요" 알림(장소·예약명 포함)을 보낸다. 기존 확정 알림을 고치는 대신 **추가 알림**(멱등 키: tableId+venueAssigned). 알림 유형이 PRD에 없으면 기존 유형 재사용하고 decisions.md에 [CC] 기록.
2. **`/me/recommendations` 빈 배열**: 11단계 시점(피드백 제출 후, S4·S5 OPEN)에서 왜 비는지 원인 확인 → 수정. 추천 조건(지역·날짜·이미 신청한 회차 제외 등)을 완료 보고에 한 줄로. user24 보관 크레딧이 홈/신청 화면 API에 나오는지도 확인(안 나오면 API 응답에 포함만, 프론트는 `v2-to-pm.md`에 메모).
3. **어드민 테이블 상세 상태 이력**: 테이블·구성원 상태 변경 이력(시각·이전→다음·주체 SYSTEM/SCHEDULER/OPERATOR·원인)을 API에 추가하고 `/admin/tables/:id`에 타임라인으로 표시. 기존 StatusHistory 사용.
4. 끝나면 배포 사이트에서 **5·7·11단계만 재확인** → **시드 초기화로 원상복구**.
