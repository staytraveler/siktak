# 작업지시서 (docs/tasks)

기획 세션이 작성하고, Claude Code가 읽고 실행한다.
사용자는 Claude Code에 `/task 2.2`처럼 번호만 전달한다.

## 규칙

1. **지시서 1개 = 블레이버스 워크(Depth 2) 1개.** 파일명은 `<아젠다>.<워크>-<이름>.md`.
2. 지시서의 **"사용자가 직접 할 일"**은 Claude Code가 대신하지 않는다. 필요한 값(URL, 키 등)은 사용자에게 요청한다.
3. 지시서와 `CLAUDE.md`·`docs/domain/` 명세가 충돌하면 **멈추고 사용자에게 확인**한다.
4. 작업이 끝나면 지시서 맨 아래 **"완료 보고"**를 채우고, `docs/progress.md`에도 기록한다.
5. 지시서 본문은 수정하지 않는다. 계획과 달라진 점은 완료 보고의 "변경 사항"에 적는다.
