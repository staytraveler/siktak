## 1차 (PM이 배포 사이트에서 직접 확인한 것)
1. **홈(신청 전)**: 첫 화면에 다음 행동이 안 보인다. 히어로 바로 아래(첫 화면 안)에 큰 PrimaryButton "이번 주 식탁 고르기 →"(/app/slots). 프로필이 미완성이면 그 위에 "프로필 먼저 채우기" 카드. 일러스트 높이 줄여서 버튼이 스크롤 없이 보이게(390×812).
2. **일정 목록 TicketCard에 저녁 시간 표시**: 지금은 신청 마감·매칭 시각만 있고 **식사 시작 시각이 없다**. 날짜 옆/아래에 "19:30" 같은 시작 시각을 가장 크게. 신청 마감은 "D-n 마감" 같은 짧은 표기, 매칭 시각은 작은 보조 텍스트로.
3. **일정 선택 상태가 안 보임**: 카드 탭 → 선택 표시(테두리 accent + 오른쪽 위 순번 ①②③). 다시 탭하면 해제, 순번 재정렬. 하단 고정 바 "N개 선택 · 다음 →"(선택 0이면 비활성). 결제 수단 버튼은 이 다음 단계에서.
4. **"멤버십·크레딧 (준비 중)" 숨김**: 보관 크레딧이 있는 사용자에게만 "보관 이용권 사용" 선택지 노출, 없으면 1회권만.
5. **로그인 테스트 계정 카드**: 누르면 즉시 눌림 표시 + 로딩("로그인 중…"), 실패 시 메시지. 카드 하단에 "탭하면 바로 로그인" 안내.

### 3차 — 전체 톤 변경 (사용자 지시, 최우선)
**레퍼런스 이미지: `docs/design/reference/ref-home.png` — Read 도구로 열어서 직접 볼 것.** 사용자가 원하는 홈 화면이며, **참가자 앱 전체를 이 톤으로** 바꾼다. 기존 design-guide의 "둥근 모서리 없음·굵은 먹선·오프셋 그림자"는 **폐기**.

레퍼런스에서 읽어야 할 규칙:
- **모서리**: 카드·버튼·히어로 모두 둥글게 (카드 14~16px, 버튼 10~12px, 칩은 완전 pill).
- **선·그림자**: 얇은 연한 테두리(#E8DFD2 계열) + 아주 옅은 그림자. 굵은 1.5px 먹선·4px 오프셋 그림자 제거.
- **헤더**: 왼쪽 "우연한 식탁"(세리프), 오른쪽 원형 프로필 아이콘 버튼. 매스트헤드 호수 표기(No.12) 제거.
- **히어로 카드**: 둥근 머스터드 카드 안에 작은 영문 라벨(자간 넓게) + 세리프 큰 제목 + 한 줄 설명 + 아이콘 붙은 날짜, 오른쪽에 일러스트(이미지 슬롯 `Illustration`). 상태별로 제목·라벨·색 바뀜.
- **주 버튼**: 히어로 바로 아래 꽉 찬 먹색 둥근 버튼 ("신청 상세 보기 →" 등 상태별 다음 행동).
- **리스트 카드**: 왼쪽 와인색 날짜 블록(일·월·요일) + 지역(세리프) + 설명 + **아이콘 달린 상태 pill**(신청 완료·결제 완료·매칭 대기 등, 연한 배경 색으로 구분) + 오른쪽 `>`.
- **섹션 헤더**: 영문 이탤릭 제목 + 오른쪽 "전체 보기 →"(와인색) + 아래 얇은 선.
- **아이콘**: 라인 아이콘 사용 (`lucide-react` 설치 허용). 하단 내비 4개 모두 아이콘+라벨, 활성은 와인색 + 아래 점.
- **프로필 줄**: 원형 아바타 아이콘 + 이름(아이디) + 오른쪽 테두리 버튼.
- 색 토큰(paper·ink·accent 와인·mustard)은 유지, 여백 넉넉하게.

적용 순서: ① 공통 컴포넌트(토큰·Card·Button·Pill·Header·BottomNav)를 먼저 바꿔서 전 화면에 퍼지게 → ② 홈을 레퍼런스와 거의 같게 → ③ 일정·결제·알림·기록·단체방·매칭 실패·로그인을 같은 부품으로. 1차 5개 항목은 이 톤 위에서 처리.
**히어로 이미지 (사용자 제공)**: `frontend/public/illustrations/home-hero.jpg` (1400×787, 머스터드 배경 + 오른쪽 램프·테이블). `assets.ts`에 `homeHero` 추가하고 `Illustration` 슬롯으로 사용.
  - 히어로 카드 **배경 이미지**로 깔기: `object-fit: cover; object-position: right center`, 카드 높이 약 200px. 글자는 왼쪽(그림은 오른쪽 40%에 있음). 레퍼런스처럼 보이게 조정.
  - 이미지 배경색과 카드 배경을 같은 머스터드로 맞춰 경계가 안 보이게(이미지 왼쪽 픽셀 색 추출해서 토큰 `mustard` 값 조정 가능).
  - 쓰는 곳: 홈 히어로(모든 상태), 로그인 상단. 매칭 실패·확정 등 다른 상태도 일단 같은 이미지 + 문구만 다르게 (추후 사용자가 상태별 이미지 줄 수 있음).
`docs/design/design-guide.md` 1·2·4장을 위 규칙으로 갱신.
